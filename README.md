# EvoWeb blog

Source of the blog post for **EvoWeb: A Benchmark for Coding Agents on Evolving Web Applications**,
served at <https://two-delta.github.io/evoweb-blog/>.

- Paper: [arXiv:2610.16402](https://arxiv.org/abs/2610.16402)
- Code: [github.com/two-delta/EvoWeb](https://github.com/two-delta/EvoWeb)
- Dataset: [huggingface.co/datasets/TD-Labs/EvoWeb](https://huggingface.co/datasets/TD-Labs/EvoWeb)

The page is a single static `index.html` with no build step. `figures/` holds the paper's figures,
`shots/` the judge's screenshots from the released example run (`examples_artifacts/examples.zip`
in the code repository), and `media/` the judge demo video.
